# @ibvap/core-types

Canonical Pydantic v2 data models and TypeScript interfaces for the Intelligent Border Video Analytics Platform (IBVAP).

## Modules
- `ibvap_core_types.sensor`: Sensor & camera configurations
- `ibvap_core_types.detection`: Bounding boxes & tracking
- `ibvap_core_types.alert`: Tactical alerts & Merkle leaf hashing
- `ibvap_core_types.cot`: Cursor-on-Target (CoT) XML schema data models
- `ibvap_core_types.embedding`: 512-dimension ArcFace biometric embeddings
